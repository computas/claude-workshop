# Dette repoistoriet er en samling av prosjkekter som danner bakgrunn for en intern workship om Agentisk utvikling i Computas

Felles for alle prosjektene er at de er laget med "samme" prompt  (utgangspunkt) dokumentert under docs katalogen


- claude-code-generated : En lego butikk på nett med en del kjente feil og mangler.
  Satt opp med claude code og noen ferdige skills . I dette prosjektet er det også en read.me fil som beskriver oppgaver til workshippen. Bruk gjerne dette prosjektet dersom du skal delta på den tekniske claude code workshoppen.
- claude_cowork_generated_code : En lego butikk på nett. Løsningen er wibet i cloude_cowork
- gemini_generated_code : En lego butikk på nett. Løsningen er wibet i gemini AI
